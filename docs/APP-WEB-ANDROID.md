# Machado Gestão web — mesma interface do Android

- [Abrir aplicativo](https://barbearia-machado-rose.vercel.app/app).
- [Adicionar ao iPhone](https://barbearia-machado-rose.vercel.app/app/instalar).
- [Administração para PC](https://barbearia-machado-rose.vercel.app/admin).

O aplicativo web usa os mesmos componentes da edição Android 1.19.9, com Caixa, Comandas, Agenda, Clientes e Menu. Login normal com e-mail e senha. A sessão é mantida enquanto for válida. Criar conta abre uma unidade independente; guarde os códigos de recuperação.

No iPhone: **Safari → Compartilhar → Adicionar à Tela de Início**. Ative **Abrir como App da Web**, se aparecer. Abra pelo ícone Machado Gestão. Precisa de internet e dispensa assinatura Apple para este modo web.

No Menu, **Versão web admin** abre o painel de PC; **Versão web** abre este aplicativo. Atualize puxando para baixo a partir do topo. Gráficos, metas administradas e formulários são compartilhados com o APK. [Entrega e verificações atuais](ENTREGA-1.19.9.md).
