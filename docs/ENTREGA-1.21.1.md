# Gestão 1.21.1 / Profissional 1.3.1

Republicação autorizada em 18/11/2026. Mantém o design aprovado, Início central, funções, contas, isolamento e integração do agente da versão anterior.

Os novos APKs foram gerados com bundles JavaScript legíveis (`build.minify=false`), sem mudar o comportamento da aplicação. A análise local do código-fonte, dependências e compilações legíveis não encontrou ameaças. Os dois APKs completos novos também foram verificados no Microsoft Defender Antivirus, motor 1.1.26100.4 e assinaturas 1.463.359.0, com resultado “found no threats”. Não houve desativação da proteção nem criação de exclusões.

O resultado documenta a verificação local realizada. Não confirma a causa da detecção nos APKs anteriores, que permanecem suspensos; nenhum arquivo foi enviado para análise externa. A assinatura Android, os pacotes e os códigos de versão dos novos arquivos foram conferidos. Os testes de build, renderização das seções e cálculos financeiros passaram; a interface compilada foi exercitada com dados de teste e sem escrita no banco de produção.

- Gestão: versão 1.21.1, código Android 34.
- Profissional: versão 1.3.1, código Android 9.
- Tamanhos, SHA-256 e resultado da verificação: `releases/android/manifest-1.21.1.json`.
- APKs assinados: `releases/android/`. Instalar os novos arquivos; não reutilizar os links de 1.21.0/1.3.0.

Nenhuma migração de banco, alteração de comissão, mudança de credenciais ou de controles de WhatsApp nesta republicação. PC, celular e iPhone pela versão web mantêm seus endereços.
